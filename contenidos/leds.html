Introducción y Control de LEDs

¿Qué es Arduino?

Arduino es una plataforma de código abierto diseñada para facilitar la creación de proyectos electrónicos interactivos. Está compuesto por:

  • Hardware: Una placa electrónica (como Arduino Uno, Nano o Mega) con microcontrolador integrado.
  • Software: Un entorno de desarrollo (Arduino IDE) donde se escribe y carga el código.

Se programa usando un lenguaje basado en C y C++, pero simplificado para facilitar el aprendizaje, especialmente para principiantes.

¿Para qué sirve Arduino?

Con Arduino puedes:

  • Encender y controlar LEDs
  • Leer datos de sensores (temperatura, luz, movimiento, etc.)
  • Controlar motores y servomotores
  • Crear proyectos de robótica, domótica y automatización

Cuando trabajamos con Arduino, el código se estructura en dos funciones principales que exploraremos a continuación.

Función void setup()

void setup() {
  // Código de configuración
}

La función setup() se ejecuta una sola vez cuando:

  • Se enciende la placa Arduino
  • Se presiona el botón de reset
¿Para qué sirve?

Se utiliza para configurar el programa. Aquí se definen:

  • Pines de entrada o salida
  • Comunicación serial
  • Configuración inicial de sensores o módulos

Función void loop()

void loop() {
  // Código que se repite
}

La función loop() se ejecuta repetidamente mientras Arduino esté encendido, creando un ciclo infinito.

¿Para qué sirve?

Aquí va la lógica principal del programa:

  • Encender y apagar LEDs
  • Leer valores de sensores
  • Tomar decisiones con condicionales
  • Ejecutar acciones de forma continua

Función pinMode()

La función pinMode() se utiliza para configurar el comportamiento de un pin digital, indicando si funcionará como entrada o salida.

Sintaxis:

pinMode(pin, modo);

pin → Número del pin digital (por ejemplo: 2, 8, 13)

modo → Tipo de funcionamiento del pin

Modos disponibles:
  • OUTPUT (Salida): El pin envía voltaje hacia un componente (LED, relé, buzzer, etc.) 
    pinMode(13, OUTPUT);
  • INPUT (Entrada): El pin recibe información de un dispositivo externo (botón, sensor, etc.) 
    pinMode(2, INPUT);

Nota: Esta función se usa normalmente dentro de void setup().

Función digitalWrite()

La función digitalWrite() se utiliza para enviar un valor digital a un pin configurado como salida, es decir, para encender o apagar un dispositivo.

Sintaxis:

digitalWrite(pin, valor);

pin → Número del pin digital

valor → HIGH o LOW

Valores disponibles:
  • HIGH: Envía voltaje (generalmente 5V o 3.3V) - Enciende el dispositivo
  • LOW: Corta el voltaje (0V) - Apaga el dispositivo

Se usa principalmente para controlar LEDs, relés, buzzers, entre otros componentes.

Ejemplo: Parpadeo de LED (Blink)

Este es el programa más básico de Arduino, ideal para comenzar a programar. 

void setup() {
  pinMode(13, OUTPUT);  // Configura el pin 13 como salida
}

void loop() {
  digitalWrite(13, HIGH);  // Enciende el LED
  delay(500);              // Espera 500 milisegundos
  digitalWrite(13, LOW);   // Apaga el LED
  delay(500);              // Espera 500 milisegundos
}

Explicación: Este código hace que el LED conectado al pin 13 parpadee cada medio segundo (500 ms encendido, 500 ms apagado).

Actividad 3: Creación de Funciones

Crea una función que reciba como parámetro el número de pin digital y que se encargue de encender y apagar ese LED con un retardo. 

void parpadearLED(int pin) {
  digitalWrite(pin, HIGH);
  delay(500);
  digitalWrite(pin, LOW);
  delay(500);
}

Utiliza esta función para simplificar tu código y hacerlo más reutilizable.
