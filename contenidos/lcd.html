Configuración de pines del LCD

La pantalla LCD 16x2 cuenta con 16 pines. Al posicionar el cursor sobre cada uno en el simulador, se muestra su función. A continuación se detalla la conexión correcta de cada pin:

2VCCTerminal positiva (5V)
3V0Control de contraste → conectar a terminal negativa (GND)
4RSSelección de registro → pin digital 7
5RWLectura/Escritura → terminal negativa (GND) para modo escritura
6E (Enable)Habilitación → pin digital 6
7–10DB0–DB3No se utilizan en modo de 4 bits
11DB4Pin digital 5
12DB5Pin digital 4
13DB6Pin digital 3
14DB7Pin digital 2
15LED Ánodo (A)Terminal positiva (5V) — retroiluminación

💡 Nota importante El pin RW se conecta a GND para mantener el LCD en modo escritura permanente, que es el modo que se utiliza en la mayoría de los proyectos con Arduino. Si se conectara a 5V, el LCD entraría en modo lectura.

Programación del LCD

Paso 1 — Incluir la librería: La librería LiquidCrystal ya viene integrada en el IDE de Arduino, por lo que no es necesario instalarla.
Paso 2 — Crear el objeto LCD: Se crea un objeto indicando los pines en el siguiente orden: RS, E, DB4, DB5, DB6, DB7.
Paso 3 — Inicializar en setup(): Se llama a lcd.begin() indicando el número de columnas y filas.
Paso 4 — Mostrar contenido en loop(): Se posiciona el cursor y se imprime el texto deseado.

Incluir la librería

#include <LiquidCrystal.h>

Crear el objeto LCD

Se instancia el objeto lcd pasando los pines en el orden: RS, E, DB4, DB5, DB6, DB7.

LiquidCrystal lcd(7, 6, 5, 4, 3, 2);

Función void setup()

Dentro de esta función se inicializa la pantalla. Los parámetros indican la cantidad de columnas y filas del LCD.

void setup() {
  lcd.begin(16, 2); // 16 columnas, 2 filas
}

Función void loop()

Para mostrar un mensaje, primero se posiciona el cursor con lcd.setCursor(columna, fila). Las posiciones comienzan desde cero, tanto en columnas como en filas.

void loop() {
  lcd.setCursor(2, 0);      // Columna 2, fila 0 (primera fila)
  lcd.print("Hola mundo"); // Muestra el texto en pantalla
}
📐 Sistema de coordenadas La esquina superior izquierda del LCD corresponde a la posición (0, 0). El primer parámetro es la columna (0 a 15) y el segundo es la fila (0 para la primera fila, 1 para la segunda).

Caracteres personalizados (íconos y emojis)

El LCD 16x2 permite crear hasta 8 caracteres personalizados (posiciones del 0 al 7). Cada carácter se define como un arreglo de 8 bytes, donde cada byte representa una fila de 5 píxeles. Los bits en 1 encienden el píxel y los bits en 0 lo apagan.

Ejemplo de uso

Para usar un carácter personalizado, primero debes crearlo en setup() con lcd.createChar() y luego dibujarlo en pantalla con lcd.write():

#include <LiquidCrystal.h>

LiquidCrystal lcd(7, 6, 5, 4, 3, 2);

byte corazon[8] = {
  0b00000, 0b01010, 0b11111,
  0b11111, 0b01110, 0b00100,
  0b00000, 0b00000
};

void setup() {
  lcd.begin(16, 2);
  lcd.createChar(0, corazon); // Registra el carácter en la posición 0
}

void loop() {
  lcd.setCursor(0, 0);
  lcd.print("Te quiero ");
  lcd.write(byte(0)); // Muestra el corazón en pantalla
}
⚠️ Consideraciones importantes La función lcd.createChar() debe llamarse dentro de setup(), antes de cualquier lcd.print(). Los índices válidos para los caracteres personalizados van del 0 al 7. Al llamar a lcd.clear(), los caracteres registrados se conservan en memoria.

Muestra tu nombre en la primera fila y el nombre de tu ciudad en la segunda fila del LCD.
Crea un ícono de corazón personalizado y haz que aparezca al lado de un mensaje.
Usa lcd.scrollDisplayLeft() para hacer que un texto largo se desplace de derecha a izquierda como un ticker.
Combina los dos mitades del corazón (izquierdo y derecho) para mostrar un corazón grande de 2×1 caracteres en la pantalla.
