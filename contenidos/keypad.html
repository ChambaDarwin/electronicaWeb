Aprende a configurar y utilizar un teclado matricial de 4×4 con Arduino, implementando un sistema de contraseña con pantalla LCD.

01

¿Qué es el teclado KeyPad?

El teclado matricial KeyPad es un periférico de entrada compuesto por una matriz de botones organizados en 4 filas y 4 columnas, lo que da un total de 16 teclas. Su funcionamiento se basa en la técnica de exploración de matriz (matrix scanning): Arduino activa cada fila y detecta qué columna responde para identificar la tecla presionada.

💡 Gracias a la técnica matricial, se controlan 16 botones usando solo 8 pines digitales del microcontrolador (4 para filas + 4 para columnas).

02

Instalación de la librería

Para comunicarse con el teclado KeyPad, es necesario instalar la librería Keypad.h. Puedes instalarla desde el Gestor de Librerías del IDE de Arduino buscando "Keypad by Mark Stanley".

main.ino 
// Incluir la librería Keypad al inicio del sketch
#include <Keypad.h>
#include <LiquidCrystal_I2C.h>
03

Configuración y mapeo del teclado

Para que Arduino reconozca cada tecla, es necesario definir tres elementos: el mapa de teclas (qué carácter corresponde a cada posición), los pines de filas y columnas conectados al Arduino, y finalmente crear un objeto de la clase Keypad que gestionará toda la comunicación.

Pines de Filas (ROWS)

A1→ Fila 1
A0→ Fila 2
13→ Fila 3
12→ Fila 4

Pines de Columnas (COLS)

11→ Columna 1
10→ Columna 2
9 → Columna 3
8 → Columna 4
configuracion_keypad.ino 
// Definir dimensiones del teclado
const byte FILAS = 4;
const byte COLUMNAS = 4;

// Mapa de caracteres: cada posición corresponde a una tecla
char teclas[FILAS][COLUMNAS] = {
  {'1','2','3','A'},
  {'4','5','6','B'},
  {'7','8','9','C'},
  {'*','0','#','D'}
};

// Asignación de pines físicos en el Arduino
byte pinesFilas[FILAS]      = {A1, A0, 13, 12};
byte pinesColumnas[COLUMNAS] = {11, 10, 9, 8};

// Crear el objeto teclado usando la clase Keypad
Keypad teclado = Keypad(makeKeymap(teclas),
                         pinesFilas,
                         pinesColumnas,
                         FILAS, COLUMNAS);

🔧 makeKeymap() convierte la matriz bidimensional de caracteres al formato interno que la librería Keypad necesita para asociar cada combinación de fila/columna con su carácter correspondiente.

04

Lectura de teclas y visualización en LCD

El método teclado.getKey() devuelve el carácter de la tecla presionada, o NO_KEY si no se presionó ninguna. La condición if(letra) evalúa el resultado: en C++, un carácter nulo equivale a falso, por lo que el bloque interno solo se ejecuta cuando el usuario presiona efectivamente una tecla.

loop.ino 
void loop() {

  // Leer la tecla presionada (devuelve '\0' si no hay ninguna)
  char letra = teclado.getKey();

  // Solo ejecutar si se presionó una tecla válida
  if (letra) {
    lcd.setCursor(i, 1);  // Posicionar cursor en la fila inferior
    lcd.print(letra);       // Mostrar el carácter en la LCD
    user[i] = letra;        // Guardar el carácter en el arreglo
    i++;                    // Avanzar a la siguiente posición
  }

}
05

Sistema de contraseña

El sistema de contraseña compara lo que el usuario ingresa con una contraseña predefinida. Se utilizan dos arreglos de caracteres: uno que almacena la contraseña correcta y otro que recoge los caracteres ingresados por el usuario en tiempo real. La función strcmp() de la librería estándar de C compara ambas cadenas de texto.

📌 ¿Por qué longitud 4? La contraseña "123" ocupa 3 caracteres más el carácter nulo de terminación '\0' que C agrega automáticamente, totalizando 4 posiciones en memoria.

variables_globales.ino 
// Contraseña correcta (3 caracteres + terminador nulo '\0')
char password[4] = "123";

// Arreglo para almacenar los caracteres ingresados por el usuario
char user[4];

// Índice para rastrear la posición actual de ingreso
int i = 0;

Una vez que el usuario ha ingresado 3 caracteres (cuando i == 3), se realiza la comparación. La función strcmp() devuelve 0 si ambas cadenas son idénticas, o un valor distinto de cero si difieren.

validacion_contrasena.ino 
if (i == 3) {
  lcd.setCursor(0, 1);

  // strcmp() devuelve 0 si las cadenas son iguales
  if (strcmp(password, user) == 0) {
    lcd.print("CORRECTO");
    // Aquí puedes activar un LED verde, servo, etc.

  } else {
    lcd.print("INCORRECTO");
    digitalWrite(A2, HIGH);  // Encender LED de alerta
  }

  // Reiniciar el índice y limpiar la pantalla después de 2 segundos
  i = 0;
  delay(2000);
  digitalWrite(A2, LOW);
  lcd.clear();
}
